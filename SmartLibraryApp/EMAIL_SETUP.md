# Email setup

- `SMART_LIBRARY_SMTP_HOST` — SMTP server, for example `smtp.gmail.com`
- `SMART_LIBRARY_SMTP_PORT` — `465` for SSL (default) or `587` for STARTTLS
- `SMART_LIBRARY_SMTP_USER` — SMTP account username
- `SMART_LIBRARY_SMTP_PASSWORD` — SMTP password or provider app password
- `SMART_LIBRARY_SMTP_FROM` — optional sender email; defaults to the SMTP user
- `SMART_LIBRARY_SMTP_FROM_NAME` — optional sender name; defaults to
  `Smart Library System`
